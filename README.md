# AZ Tech Frida — Sawmill & Timber Operations PWA

Official web application for **AZ Tech Frida**, premier timber suppliers and sawmill operators located in Sandhill, Belize District.

---

## 🪵 About the Project

This Progressive Web Application (PWA) allows local contractors, international buyers, and forestry clients to browse native Belizean timber species, estimate board footages, and submit instant orders or queries directly to our Sandhill team via web or WhatsApp.

---

## 📍 Company & Operational Details

* **Facility Location:** Mile 19 ½, Phillip Goldson Highway, Sandhill, Belize District, Belize
* **Primary Export Hubs:** Big Creek Port & Bomba Dock
* **Direct Mobile / Orders:** +501 603-9000
* **Primary Species:** Genuine Mahogany, Santa Maria, Yemeri, Caribbean Pine, Honduran Rosewood, Cabbage Bark & Nargusta.

---

## ✨ Key Features

1. **Board Feet (BF) Estimator:** Real-time formula calculator for custom dimensional lumber orders.
2. **Belize Hardwood Catalog:** Interactive catalog with search and density profiles.
3. **Milling & Processing Services:** Kiln Drying (KD), Surfaced 4 Sides (S4S), Rough Sawn, and Live Edge Slabs.
4. **Instant WhatsApp Integration:** One-click pre-formatted quote dispatch directly to the operational team.
5. **Offline PWA Support:** Built for remote timber tracts and field usage on iOS and Android devices.

---
